Pattern Quest
=============

Files in this bundle:
- pattern-quest.html: the learning webpage
- manifest.webmanifest: home-screen app metadata
- service-worker.js: offline caching
- app-icon-180.png and app-icon-512.png: app icons
- ASSET-LICENSE.md: visual asset notes

To use as an iPhone/iPad home-screen app, host all files together over HTTPS.
Open pattern-quest.html in Safari, tap Share, choose Add to Home Screen, then tap Add.
Offline loading is available after the first successful visit and service-worker setup.
